A calculator built while learning JavaScript fundamentals — DOM manipulation, event handling, and functions.

- ✅ Basic operations (+, -, ×, ÷) working
- ✅ Backspace button working
- ⏳ Keyboard support — coming soon

- Event handling (`onclick` events, keyboard events)
- String manipulation (`.slice()` for backspace functionality)
- Using `eval()` to evaluate mathematical expressions
- Refactoring repeated code into reusable functions
