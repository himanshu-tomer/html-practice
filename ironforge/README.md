# IronForge 🏋️‍♀️

A simple, responsive-in-progress gym & fitness landing page built while learning frontend fundamentals — HTML, CSS, and layout techniques like Flexbox and positioning.


## Screenshot
![Uploading Screenshot (299).png…]()


## Features

- Hero section with a full-screen background image and dark overlay for readability
- Navbar with hover states
- Membership signup form (Name, Age, Gender, City)
- Custom styled buttons and containers

## Built With

- HTML5
- CSS3 (Flexbox, positioning, custom styling)

## What I Learned

This was one of my first projects practicing:
- Fixing common HTML structure bugs (unclosed tags, mismatched elements)
- Centering elements using `margin: auto`
- Adding and styling a background image with `background-size`, `background-position`, and overlay gradients
- Debugging with browser DevTools (Console & Network tabs)
